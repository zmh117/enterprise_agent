# 钉钉应用访问来自路由命中和启用用户身份

第一版 DingTalk Application Access 不设置额外应用用户白名单。钉钉消息命中绑定活动 Application Publication 的连接器，且实际发送人能够解析为已启用内部用户时，才可创建该应用的 Job；工具调用还必须同时通过 Application MCP Tool 显式子集和当前 Role scope 的实时校验。群聊按每条消息的实际发送人独立判断，不存在群级共享主体。

未绑定钉钉身份或内部用户已停用时拒绝访问并返回安全中文提示。ONES 身份是否绑定不影响普通钉钉对话，也不自动授予 MCP 工具权限。该决定只定义钉钉入口，不扩大其他 Trigger 类型的访问模型。
