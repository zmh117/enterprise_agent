# 复用外部身份面板并区分本人和管理员模式

继续复用同一个外部身份面板，不新建第二套 ONES 绑定组件。模式由入口和对应授权边界决定，不再比较当前认证主体与目标用户：独立的“我的外部身份”入口使用本人模式；受 `users.read` 等治理权限保护的“人员管理 → 用户详情”入口始终使用管理员治理模式，即使管理员查看自己的人员记录。

普通用户通过“我的外部身份”入口使用本人模式，但不能访问人员列表、角色、会话或其他用户详情。本人模式只读展示当前钉钉身份，并允许本人绑定、重新验证、选择默认 Team 和软解绑自己的 ONES 身份；不扩展本人钉钉绑定、启停或解绑权限。治理模式保留钉钉治理动作，并只读查看或停用 ONES 身份，但不得渲染 ONES 邮箱密码表单、代替用户重新验证或代替用户解绑。本人模式不展示 `unbound` 历史，治理模式则把这类记录保留在默认折叠的只读历史区域。

后端 ONES 自助接口必须从认证会话取得当前用户 ID，不接受客户端提供目标 `user_id`。两个入口读取同一外部身份事实，但以不同权限边界呈现，不建立独立状态或业务调用凭据。
