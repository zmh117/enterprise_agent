# 复用外部身份面板并区分本人和管理员模式

继续复用现有“用户详情 → 外部身份”面板，不新建第二套 ONES 绑定组件。当前主体查看自己时进入本人模式，可以绑定、重新验证、选择或切换默认 Team 以及解绑自己的 ONES 身份和凭据；管理员查看其他用户时进入治理模式，只显示外部 User ID、默认 Team、凭据状态和验证时间，并仅可禁用或解绑，不渲染邮箱密码表单。普通用户通过“我的外部身份”入口复用同一面板，但不能访问人员列表、角色、会话或其他用户详情。后端 ONES 自助接口必须从认证会话取得当前用户 ID，不接受客户端提供目标 `user_id`；现有钉钉身份治理流程不因本决定扩展范围。
