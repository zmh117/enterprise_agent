# 按钉钉企业建模身份并以观察记录关联应用

钉钉外部身份属于以真实 Corp ID 标识的钉钉企业，不属于接收消息的某一个钉钉应用连接。平台新增第一类“钉钉企业”，多个应用连接引用同一企业；钉钉身份按“企业 + 钉钉用户 ID”唯一解析，每个“内部用户 + 企业”最多保留一个当前身份。已验证 Corp ID 不允许直接编辑，企业名称可以审计修改，企业的待验证、启用、停用和归档生命周期与连接心跳状态分别治理。

身份与应用连接之间使用幂等的多对多观察记录，只保留首次和最近受信时间，用于说明来源与排障，不表示用户绑定应用或获得应用授权。身份停用或解绑对该企业的全部应用连接生效；应用访问仍由连接命中的 Application Publication 和当前启用用户独立决定。受信消息中的最新非空 `senderNick` 按事件时间和稳定事件 ID 单调更新身份昵称，并形成不含消息正文的精简变更审计。

不采用“每个应用复制一份身份”，因为同一企业用户经多个机器人出现时会产生重复人员映射和相互漂移的状态；也不继续使用自由租户字符串或身份行上的单一 `connector_id`，因为它们无法证明真实企业边界。当前旧钉钉记录均为测试数据，因此通过非生产专用的预检、固定确认和事务命令清理重建，不实现旧字段兼容或历史事件回填；平台人员、ONES、业务配置以及所有 Job、Tool 调用和投递历史保持不变。
