## ADDED Requirements

### Requirement: 持续采集保留整页可见业务文字与操作上下文

浏览器渠道 SHALL 在用户已开启持续采集且仍获授权的业务页面上，将当时的页面标题、整页可见业务文字、控件与行列关系和后续变化作为同一录制的证据。对于可识别的人工操作，系统 MUST 保留操作发生时可观测的目标名称、相关业务行或字段，以及策略允许的实际输入值或选项。证据在离开页面采集端前 MUST 执行脱敏，沿用账号、标签页、车间和录制授权边界。

#### Scenario: 打开菜单并区分同名操作

- **WHEN** 用户点击菜单文字内的图标，在工单列表第二行点击两行都有的“编辑”，在弹窗修改数量并确认
- **THEN** 按事件顺序可读到页面标题、菜单名称、第二行可见的工单标识、按钮名称、字段名称及实际提交的控件值；已有旧值观测时可关联前后值
- **AND** 若表格缺少可区分业务行的文字或标识，结果保留所见信息并说明该行无法唯一确定

#### Scenario: 基线及增量反映当时的整页业务内容

- **WHEN** 页面含操作区以外的表格、标题和状态文字，随后切换选项卡、原地更新文本或显示原先隐藏的弹窗
- **THEN** 结合基线和增量可还原操作前后各自可见的业务内容与控件状态，未操作区域的可见文字也能查询
- **AND** 未展示的隐藏内容、助手自身、无法访问的嵌入文档和无法读取的绘图区域不得冒充已采集业务文字；发生覆盖或预算缺口时须能识别

#### Scenario: 输入、关联文本与快照统一执行本地脱敏

- **WHEN** 表单同时出现普通数量、受限输入、密码、凭据、原始消息区域及用户配置的敏感区域
- **THEN** 普通允许字段记录确认时的实际值；敏感内容在标题、目标、标签、所属行、基线与增量各路径都被排除或遮蔽，在本地队列和上传内容里不出现
- **AND** 开启全页文本遮蔽或收紧允许输入字段时，动作详情采用相同限制

#### Scenario: Agent 依据观测重建操作经过

- **WHEN** Agent 查询本次录制，窗口中同时包含人工操作、定时请求、加密响应或尚未上传完整的证据
- **THEN** Agent 可按顺序读取操作详情及关联的页面状态，分别说明有依据的业务步骤和未观测部分
- **AND** 只有定时请求时可描述该时段可见的接口活动；缺少操作证据不能证明用户没有操作，也不能从密文断言业务结果

#### Scenario: 历史结构录制继续可读

- **WHEN** 查询修改前生成的操作和页面基线
- **THEN** 原有时间、动作与节点引用可用，页面文字和输入值标为未采集；不得用当前页面或后续请求补写历史值
