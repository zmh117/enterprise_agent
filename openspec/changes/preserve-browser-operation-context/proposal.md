# Proposal

## Why

用户需要根据浏览器持续采集记录还原一次 MES 操作。当前插件在采集端清空快照文本和输入值，每次点击只携带动作、标签和节点编号；即使上传和核对全部成功，Agent 也无法从这些字段识别菜单、业务行和修改内容。

## What Changes

- 在获授权的采集页保留页面标题、整页可见业务文字及其随操作发生的变化，先按策略脱敏，再写入队列和上传。
- 每次人工操作附带可辨认的控件、行或表单上下文，以及允许记录的选择或提交值。使同名按钮、相邻的业务行可以区分。
- Agent 按观测顺序读取操作和当时的页面状态。旧录制、隐藏内容、未覆盖页面区域和未完成上传产生的证据缺口，要能与确实观测到的事实区分。

## Impact

影响插件持续录制脚本、后台事件投影，以及平台的录制查询和对 Agent 的查询说明。使用既有车间绑定、录制授权、证据分片与 Loki 读回机制。验证使用虚构业务数据；真实 MES 验收单独记录。
