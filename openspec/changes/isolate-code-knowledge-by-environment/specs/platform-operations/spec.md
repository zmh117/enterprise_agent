## ADDED Requirements

### Requirement: 代码答案与问答历史必须按环境持久化
代码分析、版本化答案和最终问答记录 MUST 保存服务端确定的稳定环境身份。答案身份 MUST 同时包含环境、来源、SVN 版本、问题、适用条件及可见范围；相同问题在不同环境独立保存和纠错。私有问答历史 MUST 按任务、知识库和环境幂等记录，所有引用必须属于同环境。已有无环境记录 MUST NOT 自动回填、被检索或作为其他环境的引用；新写入 MUST 拒绝空环境。现有共享 PG/Qdrant、检出及源码读写互斥仍生效。

#### Scenario: 两个环境保存相同问题
- **WHEN** A 和 B 使用相同知识库、源码版本、问题和条件保存经验证答案
- **THEN** 获得不同答案身份，A 的纠错不改写 B，问答历史分别记录环境

#### Scenario: 旧无环境数据
- **WHEN** 升级前已有无环境答案、索引或搜索凭证
- **THEN** 新查询不返回这些答案，旧凭证不能进入新分析或全文读取，不猜测其所属环境

#### Scenario: 复制跨环境引用
- **WHEN** 保存 B 的问答历史时携带 A 的答案引用
- **THEN** 保存被拒绝，不把 A 的结论记录为 B 的已验证答案
