## ADDED Requirements

### Requirement: Agent 可在本轮绑定的录制中按需查询操作与请求

平台 SHALL 在固定 tool-mcp 的代码工具目录提供只读 `search_recording` 与 `get_recording_evidence`。每次调用 MUST 从受信的 RUNNING Job 确定插件会话、当前用户、租户、应用、Connector、发布、执行范围及录制版本，校验当前授权、冻结的 Tool/schema 与源数据可用性。模型不得提供身份、录制切换参数或对象地址。已知 evidence ID、历史命中和游标均不授予读取权限。

#### Scenario: 从保存操作定位接口再核对响应
- **WHEN** Agent 在当前录制中按类型、时间窗、路径模板、方法、HTTP 状态、业务结果、操作类型或关联引用过滤
- **THEN** 搜索按稳定顺序返回有界命中、带版本归属的证据 ID、关联依据和覆盖情况；按该 ID 可读单条请求、响应或操作的业务字段，包括此前未登记的嵌套字段，并区分请求侧与响应侧的未采集、策略省略及截断状态

#### Scenario: 搜索超出响应预算或没有命中
- **WHEN** 匹配记录超出本次条数或字节预算，或当前筛选条件没有匹配
- **THEN** 超预算时明确标记并给出可用的续页或收窄条件提示，游标绑定授权、版本与筛选条件；零命中仍返回采集缺口，Agent 只能说明本次覆盖范围内的结果

#### Scenario: 冻结引用失效或越界查询
- **WHEN** Job 没有绑定、工具未获准、当前权限被撤销、录制到期，或 ID、游标来自另一录制
- **THEN** 在对外返回数据前拒绝，不暴露其他录制或扩大查询范围，不自动从插件补取；普通审计只投影标识、计数、耗时和状态，详细审计沿用现有权限与保留策略
