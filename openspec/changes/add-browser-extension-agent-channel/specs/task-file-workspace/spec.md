## ADDED Requirements

### Requirement: File Service 独立保存浏览器录制的受控明细

系统 MUST 将录制作为独立于 Job 的诊断数据集。可检索事实由 PostgreSQL 保存，较大的业务明细按有界分片经 File Service 存入 MinIO。只有 File Service 可访问对象位置与凭据；明细读取必须绑定已授权版本与证据 ID，Runtime 只得到命中记录的业务字段和省略说明。录制不得因会话绑定成为任务附件、自动文件工作集或跨 Job 共享沙箱。

#### Scenario: 上传在对象写入后中断
- **WHEN** 明细写入成功但索引或发布事务失败
- **THEN** 未发布数据不可查询；同一版本和片号可以幂等恢复，暂存到期后可重试清理孤立对象和索引

#### Scenario: Job 已回收或录制到期
- **WHEN** 首轮 Job 已终结而录制仍在发布时固定的内容保留期内
- **THEN** 其沙箱清理不影响下一轮授权读取；到期后立即停止读取，后台可重试清除索引、暂存及明细，多次追问不延长到期时间

#### Scenario: 一次授权只访问指定分片或命中行
- **WHEN** 平台上传清单中指定的分片，或已授权工具查询当前 Job 绑定的一条证据
- **THEN** File Service 验证签名、用途及资源绑定，上传只写入确定性对象，读取只返回命中行；只有既有维护入口能够回收已到期的内容
