## ADDED Requirements

### Requirement: 授权 SVN 内容不按敏感启发式规则阻断
SVN 单文件文本 diff 和 log 提交说明 MUST NOT 按文件名关键词或敏感内容启发式正则拒绝或省略内容。工具 SHALL 继续执行知识库与路径授权、确定版本、端点校验和容量限制；提交包含越权路径或复制来源时仍按原范围投影规则省略无法安全投影的说明。平台实际连接凭据仍只在基础设施边界解析，不进入工具结果。

#### Scenario: 语言资源的差异和说明
- **WHEN** 授权文件名含 config 等片段，或差异端点与提交说明含 password 等字段及翻译字符串
- **THEN** 在版本和容量校验通过后返回文本差异及允许的提交说明，不以启发式检测阻断

#### Scenario: 仍受权限和容量约束
- **WHEN** diff 指向越权路径、非文件对象，或说明和差异超过既定容量
- **THEN** 沿用授权拒绝、单文件约束和超限/省略处理，不因取消启发式拦截扩大范围
