## MODIFIED Requirements

### Requirement: 授权源码搜索必须由宿主自动分批并报告覆盖范围
Runtime SHALL 在一个源码 Grep 调用内分页枚举授权且受 SVN 跟踪的文件，并在有界批次中验证、规范化和筛选，不能因第 65 个候选或过滤前第 10001 个目录项而直接拒绝整个查询。原生 Grep 只访问一次性授权的规范化命中文件。宿主 MUST 保持读取 grant、文件完整性、Sandbox 配额和真实停止后清理。源码 Read/Grep MUST NOT 按文件名关键词或敏感内容启发式正则阻断已授权文件。扫描字节、时间、枚举和命中容量 SHALL 有硬边界；达到边界时返回部分命中与明确不完整标记，不能声称没有相关规则。源码根或授权子目录的祖先只允许枚举已授权子集，不获得其他内容读取权。

#### Scenario: 相关代码位于原候选上限之后
- **WHEN** 授权目录包含超过 64 个符合过滤条件的文件，或超过 10000 个目录项后仍有匹配文件
- **THEN** 在预算内自动继续批次并返回相关命中，不要求模型逐次猜测子目录

#### Scenario: 语言资源和配置名称可读取与搜索
- **WHEN** 已授权且版本与内容校验通过的文本文件名包含 config、password 等片段，或内容包含密码字段翻译等字符串
- **THEN** Read 和 Grep 按普通源码处理，不因文件名或敏感词启发式规则拒绝文件或隐藏命中

#### Scenario: 非文本项或预算截断
- **WHEN** 有非文本/超单文件容量的文件被跳过或扫描预算耗尽
- **THEN** 明确覆盖不完整，不输出被跳过项正文和路径，不以零命中证明规则不存在

#### Scenario: 取消和来源变化
- **WHEN** 原 Job 取消、授权关闭或源文件身份/版本/hash 变化
- **THEN** 停止批次处理，不继续读取；清理临时副本及配额，不发布未核验片段
