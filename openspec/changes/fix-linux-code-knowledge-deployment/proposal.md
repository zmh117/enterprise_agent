## Why

Linux 文件系统实测显示，凭据入口的 `umask 077` 被 SVN 继承，检出目录为 700、文件为 600，UID 10002 的 Runtime 无法读取 UID 10003 创建的工作副本；权限失败还被误报为身份变化。首次部署缺少源码根目录初始化与预检，且配置示例遗漏代码执行器开关，导致本地可用而新虚拟机失败。

## What Changes

- 为共享源码建立固定读者组和明确的目录、文件权限；SVN 子进程独立设置创建掩码，凭据继续保持私有。
- 区分工作副本权限不足与持久身份变化，保留现有读写互斥和只读 Runtime 挂载。
- 增加显式、幂等的空目录初始化入口，预检目录存在性、所有权、挂载一致性与执行器启用状态。
- 补齐配置示例、部署与升级说明，增加跨 UID 的真实 SVN 检出与更新验收。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `platform-operations`: 补充 Linux 代码知识部署的共享权限、初始化和预检合同。

## Impact

涉及 SVN 执行器、工作副本身份错误分类、Compose、部署脚本、前端错误提示和部署文档；无数据库迁移。不启动模型、不修改现有仓库或生产工作副本、不自动部署或提交代码。目标虚拟机整套验收与本机 Linux 容器测试分别记录。
