## ADDED Requirements

### Requirement: Linux 共享源码必须具有独立于凭据的跨 UID 读取权限
系统 SHALL 使执行器创建及更新的工作副本可以被两个 Runtime 的非 root UID 只读访问，包含源码、SVN 元数据与持久身份标记。共享读权限 MUST 限制到固定读者组，不开放全局写权限；凭据和执行锁 MUST 保持私有。文件权限调整 MUST NOT 绕过既有读写互斥，不修改宿主多线程进程的全局 umask。

#### Scenario: 首次检出后两个 Runtime 读取
- **WHEN** 执行器在 Linux 本地文件系统创建工作副本
- **THEN** 两个独立只读 Runtime 均可读取源码与身份元数据，无关 UID 不可读取，Runtime 无法写入

#### Scenario: update 新增文件
- **WHEN** 无读者时执行器更新到包含新增目录和文件的版本
- **THEN** 新内容继续具备相同的组读取权限，后续 Runtime 可核验该版本

#### Scenario: 权限错误与身份错误区分
- **WHEN** 操作系统拒绝读取身份目录或标记
- **THEN** 返回固定的权限错误码，而非宣称目录身份发生变化，不暴露原始路径或源码

### Requirement: 代码知识部署必须显式初始化并预检目录和启用状态
部署 SHALL 提供显式、幂等的根目录初始化，先验证全部目标，再创建缺失目录与设定固定所有权。初始化 MUST 拒绝符号链接、路径重叠及非空且权限不符的目录，不递归修改既有工作副本。普通预检 MUST 检查目录存在性、Linux 所有权、A/B 只读挂载与执行器可写挂载指向同一根，以及状态目录挂载一致；要求代码能力时 MUST 拒绝未启用的执行器。配置示例 SHALL 显式记录该开关与目录参数。

#### Scenario: 新虚拟机缺少目录
- **WHEN** 初始化未完成或共享权限错误时运行预检
- **THEN** 启动前返回固定错误码，普通预检不自动创建空目录

#### Scenario: 初始化遇到旧数据
- **WHEN** 任一目标存在非空且不符合固定权限的目录
- **THEN** 初始化在改变任何目标前拒绝，保留全部原数据

#### Scenario: 代码执行器关闭
- **WHEN** 部署要求代码查询但 CODE_CHECKOUT_ENABLED 未启用
- **THEN** 预检失败；未要求代码查询时检查结果明确列出关闭状态
