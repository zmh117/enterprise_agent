## 背景与动机

当前格式和类型检查存在可复现失败，镜像构建未依赖后端静态检查；本地前端检查与 npm 锁文件不一致。最新知识能力、ONES 查询上限和部署事实已超过部分主规格与入口说明，管理页面集中加载产生约 1.12 MB 的主 JavaScript 包。

## 变更内容

- 修复既有格式、ONES 时间线类型收窄问题，统一前端 npm 检查入口，并让镜像构建依赖后端静态检查和前端检查。
- 按当前源码、迁移和本地测试同步已确认的知识存储/索引/检索/同步责任、ONES 查询合同及当前部署说明，保留真实环境验收边界。
- 管理页面按路由延迟加载，权限校验通过后才加载页面；提供中文加载状态并保留现有错误恢复。
- 本轮保持应用零值归一化、最近七个创建日同步窗口、数据库结构及既有授权行为；不开展大模块拆分。

## 能力

### 新增能力

无新增 canonical 领域。

### 修改能力

- `platform-operations`：质量检查与构建门禁、管理页面加载、当前知识存储与索引/受管同步、验收说明。
- `builtin-tool-resource`：补齐固定 Knowledge MCP、已发布知识资源及目录/检索的当前合同。
- `governed-api-capability`：将 `ones_query_work_items` 的累计上限与请求预算对齐当前实现，其它集合保持原合同。

## 影响范围

涉及 `Makefile`、`.github/workflows/ci.yml`、ONES REST 时间线解析、单个 Repository 的格式、前端路由与相关回归测试、三个 canonical 领域和当前入口/部署文档。无需新增依赖或 migration，不操作实际数据库、真实 Provider、现有发布物或部署；保留用户已有 README 修改及其它 active change 的任务状态。
