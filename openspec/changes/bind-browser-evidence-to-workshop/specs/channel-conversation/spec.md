# 浏览器渠道的车间范围

## ADDED Requirements

### Requirement: 每个允许的 MES 页面唯一关联一个已授权车间

插件 SHALL 允许用户在当前平台账号和所选业务应用下，将一个页面 URL 规则绑定到唯一的环境、基地和车间组合。可选项 MUST 来自该应用当前有效的数据范围。插件 SHALL 在浮窗显示已匹配的范围，并区分页面访问许可、业务绑定与录制状态。

#### Scenario: 同域的两个车间使用不同地址

- **WHEN** 用户允许同一域名下代表配液和包装的两个 URL 并分别保存绑定
- **THEN** 打开各自页面时各显示其完整范围，再打开相同 URL 的第二个标签页仍显示同一范围
- **AND** 保存绑定后仍由用户选择标签页并启动录制

#### Scenario: 绑定缺失或当前账号无权使用

- **WHEN** 只有旧环境配置、两个规则有歧义、权限被撤销，或登录身份切换后当前应用未获该车间授权
- **THEN** 对该页明确显示未绑定、冲突或不可用，禁止使用猜测的范围写入或查询车间信息流

### Requirement: 车间归属随来源页面和发生时间固定

对已纳入录制的页面，平台 SHALL 保留每条浏览器证据的录制、标签页实例、可确定的文档以及当时的车间归属。网络请求及其后到的响应和正文 MUST 沿用请求发起时的归属。无可证来源的记录 MUST 与车间证据区分。

#### Scenario: 同场多页与延迟响应

- **WHEN** A、C 在配液车间，B 在包装车间，C 向公共接口发起请求后页面切到包装车间，响应随后到达
- **THEN** 原请求、响应和正文仍属于 C 发起请求时的配液车间，新页面的操作属于包装车间
- **AND** 重新绑定 URL 或重试上传不会重写历史归属

#### Scenario: 同一文档切换车间

- **WHEN** 路由从一个车间切到另一个车间，顶层文档尚未刷新
- **THEN** 暂停该页采集，提示刷新或重新打开，不将留存的旧 DOM 或新的待确认页面事件记给新车间，其他已授权页继续采集
- **AND** 切回原 URL 仍保持暂停；新顶层文档和新基线就绪后恢复，之前已发出的请求保持原归属

### Requirement: 录制期间可以查询已送达的操作

已授权录制 SHALL 边采集边上传。用户可在录制中途询问已发生的操作。平台 MUST 区分已可见、尚在投递和存在缺口的证据。采集和上传 MUST 沿用所选标签页、允许来源、内容脱敏及正文预算。

#### Scenario: 离线录制与持续采集分开

- **WHEN** 用户选择持续模式并开始新录制
- **THEN** 持续模式在首次持久化、发送前完成脱敏，凭据和无法安全拆分的原文不进入待传材料；旧离线录制维持本地回放和手动共享，不能进入持续队列

#### Scenario: 断线导致最近操作尚未到达

- **WHEN** 插件采集操作后短暂断网，用户在录制结束前提问，网络随后恢复并发生重复投递
- **THEN** 可先返回已送达的证据并标明积压或覆盖未知，恢复后能增量读到补传操作，同一事件只作为一条逻辑证据

#### Scenario: 大正文跨批次

- **WHEN** 一份在采集预算内的正文超过单条日志或上传批次上限
- **THEN** 保留可验证的完整引用并支持分片读取，缺片、超采集预算和过期各有明确状态，不将截断内容标为完整

#### Scenario: 保留跨页关联所需的业务明细

- **WHEN** 用户在 A 选工单，在 C 调用 MES 接口，接口 JSON 含有工单、批次、数量和明细行
- **THEN** 持续模式保留这些业务字段和类型，可按原值核对；凭据、认证流量和原始业务消息不进入持久化材料

### Requirement: 悬浮提问按发送页冻结本轮范围

从已绑定 URL 发起提问时，平台 SHALL 校验登录人、业务应用、车间及页面录制归属，并将范围冻结到本轮 Job。切页、切车间、历史会话和重试 MUST NOT 改写已受理的范围或复用越界证据。

#### Scenario: 在 C 发问后切页

- **WHEN** 用户在 C 发出“刚才保存为什么失败”，随后切到 B 或收起再打开悬浮助手
- **THEN** 同一条消息的重试及其 Job 始终指向发送时的 C 和车间，重复提交不会产生第二个 Job

#### Scenario: 新车间与上轮会话不同

- **WHEN** 上轮问题绑定配液车间，用户在包装车间的悬浮助手发起新一轮
- **THEN** 新 Job 不能继承配液车间的录制、工具输出或对话上下文；原会话仍可从本人已授权历史访问

#### Scenario: 当前页已绑定但没有录制

- **WHEN** 用户在一个已绑定、未加入录制的标签页询问刚才的界面操作
- **THEN** 本轮仍带正确的车间路由，返回本页缺少浏览器录制的状态，不借用其他标签页或旧会话的操作充当现场证据
