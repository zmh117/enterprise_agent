## Why

七日采集停止超过窗口后缺少明确补采入口；少量新增会触发整代复制、逐块 SQL 和重复全量校验，难以及时补齐知识。用户已确认优化现有热路径、显式日期补采及停采告警，不改变授权或原子激活边界。

## What Changes

- 单次同步支持显式北京时间创建日起止范围并冻结到 run，恢复核对原范围，不修改常规七日窗口或绑定配置。
- 优化向量复用检索索引与 SQL、批量清单及检查点；同一激活过程对相同候选/内容目标只做一次独立全量点校验，仍复核配置及版本。
- 按文档修订和分块 profile 复用已核验的不可变分块，避免重新清洗切段；保持原 hash/向量/profile。
- 提供安全的阶段进度、最近成功/失败与陈旧判定，接入同步容器健康检查和结构化告警日志；不新增通知账号、外部消息或调度框架。
- 使用合成数据比较 SQL 次数/复用行为，补日期、恢复、错误与原子切换回归，不操作目标环境正在运行的补采。

## Capabilities

### New Capabilities

无新增顶层领域。

### Modified Capabilities

- `platform-operations`：显式补采、增量派生热路径及同步健康诊断。
- `builtin-tool-resource`：去重候选验证仍维持独立完整性验证、同库原子激活和当前权限复核。

## Impact

影响 knowledge CLI/application/infrastructure、可选同步 Compose、部署手册和合成测试。新增前向迁移提供复用 hash 查询索引，不修改历史迁移，不执行本机或目标环境迁移、部署、提交或推送。保留并行 Webhook/投递改动。
