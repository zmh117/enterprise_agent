## Why

当前钉钉外部身份把自由填写的租户占位值和单一内部 `connector_id` 当作身份来源，无法正确表达同一企业用户通过多个钉钉应用访问平台，也使人员详情长期展示“未设置展示名称”“租户／实例”“外部主体”等难以理解的技术字段。与此同时，ONES 身份卡没有保存 Team 名称和可靠的成功／失败使用事实，导致本人和管理员看到的状态不完整或含义模糊。

当前钉钉数据均为测试数据，适合在引入正式企业命名空间前清理重建；本次变更应一次建立可扩展到多钉钉企业、多应用连接且不混淆身份与应用授权的稳健模型。

## What Changes

- 新增以真实 Corp ID 为稳定标识的“钉钉企业”，由管理员维护企业名称，并通过首个应用的受信测试消息完成企业验证；企业具有待验证、已启用、已停用和已归档四态生命周期。
- 每个钉钉应用连接必须且只能归属一个钉钉企业；应用连接负责接入和投递，不再被建模为用户身份的所有者，也不再允许各连接自由填写可能漂移的租户标识。
- 钉钉身份按“企业 + 钉钉用户 ID”唯一解析；每个“内部用户 + 钉钉企业”最多保留一个当前有效身份，新身份只能从已验证应用产生的受信候选绑定。
- 新增钉钉应用观察记录，以“身份 + 应用连接”幂等记录首次和最近受信时间，表达一个身份可经多个应用被识别，但不产生用户与应用的绑定或授权关系。
- 使用受信消息中的最新非空 `senderNick` 维护钉钉昵称，按事件发生时间和稳定事件 ID 防止乱序回滚，并保留不含消息正文的精简昵称变更审计。
- 重构本人和管理员外部身份卡：默认展示业务可理解的昵称／用户名称、企业或默认 Team、状态、最近验证和最近使用；技术 ID、Revision、应用观察和错误码按权限收纳到展开区域。
- ONES 身份保存已验证 Team 的名称与 ID，分别呈现身份绑定状态、个人凭据状态和综合可用状态，并记录最近成功使用、最近尝试、最近错误码、错误时间及调用来源。
- **BREAKING**：删除旧钉钉测试域中的应用连接、运行态、接入事件、候选、身份和应用渠道绑定，不回填或兼容旧 `default` 占位命名空间及单一 `connector_id` 关系；清理只能通过非生产环境的一次性显式确认命令执行，不能放入常规数据库迁移。
- 保留平台人员、角色、登录会话、ONES 身份与个人凭据、API Capability、Agent、业务应用主体以及与钉钉无关的数据；清理后由管理员重新创建企业和应用连接并从新受信候选绑定人员。

## Capabilities

### New Capabilities

- `dingtalk-enterprise-governance`: 定义钉钉企业、真实 Corp ID 验证、企业生命周期、应用连接归属及受保护的测试数据重建。
- `dingtalk-identity-governance`: 定义企业内身份唯一性、受信候选绑定、昵称同步与审计、跨应用观察记录及身份治理范围。
- `external-identity-presentation`: 定义本人和管理员外部身份卡的字段语义、展示边界，以及 ONES Team 名称和凭据使用事实的持久化与呈现。

### Modified Capabilities

- `channel-connector-configuration`: 钉钉企业 App 连接必须引用一个钉钉企业并验证真实 Corp ID，不再使用自由租户字符串定义身份命名空间。
- `dingtalk-stream-ingress`: Stream 连接与消息处理必须服从企业生命周期和 Corp ID 校验，待验证消息只能形成安全验证证据。
- `dingtalk-agent-ingress`: 钉钉消息必须按企业与用户身份解析，并在创建 Agent Job 前更新昵称和应用观察证据、重新校验身份与企业状态。

## Impact

- 数据库：新增钉钉企业、应用观察、昵称审计及 ONES 凭据使用事实；调整钉钉身份唯一键、应用连接企业引用和 Team 候选结构；移除旧身份单一 `connector_id` 语义。
- 后端：影响 managed channel、DingTalk Stream、identity discovery、identity/external credential、governed API runtime、审计和一次性运维命令。
- 前端：影响渠道与触发器、未绑定钉钉用户、人员详情外部身份和“我的外部身份”页面。
- 运行环境：需要数据库结构迁移、钉钉测试数据预检与确认清理、服务重建，以及重新配置并验证钉钉企业应用。
- 安全与兼容：不持久化钉钉消息正文副本或认证材料；Token、密码、密文、Client Secret 和认证 Header 不进入身份接口或页面；现有 ONES 绑定和非钉钉业务配置保持不变。
