## 已实现

- 知识资源页面提供服务状态、构建、启动/应用版本、停止、采集计划配置、自动同步开关、立即同步、日期补采、任务重试及安全日志。
- 一个常驻调度进程执行采集计划；同一 ONES 来源按缺陷、需求、工单映射三个知识库。复用现有增量流水线，分库统计当前轮次候选，未变文档不重建索引。
- Web 与 `knowledge.sh` 使用相同持久任务队列。幂等键、来源互斥、固定日期、断点恢复和有限重试保持一致；队列满时仍能消费已有任务。
- 新增 migration 152，以及独立知识 Compose 和主项目控制器扩展。主程序负责迁移，知识项目停止后控制器仍运行；模型、向量卷及同步状态均保留。
- 日志仅记录安全事件、阶段、计数和稳定标识。同时间戳修订保留旧/新 hash 和时间戳，不记录正文、Secret 或原始终端输出。
