## 部署与传输

主 Compose 固定将 API 写入指向 Alloy 3500，读回指向 Loki 3100，两者只使用内部 HTTP。证据入口使用内部 Docker 网络，服务端口不映射到宿主。API 继续验证调用者、录制归属和分片摘要。插件与平台之间沿用既有地址和身份验证。

## 存储与升级

沿用已有私有证据桶、索引卷、七天保留期和文件服务就绪依赖。Loki 使用已确认支持 AMD64 和 ARM64 的镜像摘要。未配置专用存储身份时，一次性初始化容器在独立卷中原子创建随机凭据并在重启后复用，Loki 只读挂载。显式提供的一对凭据继续使用，配置不完整则报告初始化失败。

## 验证

解析无 profile 的主 Compose，检查容器网络和凭据挂载范围。用无证书、独立数据卷的合成项目验证普通启动、重复初始化、跨桶拒绝、API 写入、分片读回和 MinIO 落盘。
