## ADDED Requirements

### Requirement: 原生源码分析期间必须维持知识调用身份
已连接的 Runtime 知识桥 SHALL 在原生文件读取或模型分析期间，以固定有界 MCP ping 维持知识 Principal 续期，复用既有服务端签发与 continuation 通道。续期 MUST 验证未过期旧身份、当前 RUNNING Job、冻结权限与原截止；不得更换主体、扩大 scope、使用过期身份补签或延长 Job。会话关闭、取消、截止或续期失败 MUST 停止保活，失败时拒绝后续知识调用。此协议操作不读取业务信息，不计为模型工具调用。

#### Scenario: 源码分析超过五分钟
- **WHEN** Job 仍有效且源码分析跨过首个知识 Principal 到期时刻
- **THEN** 在过期前受控续期，随后保存使用当前凭证，并继续校验实际证据与版本

#### Scenario: 授权撤销或任务停止
- **WHEN** 续期时用户授权失效、任务结束或身份已过期
- **THEN** 拒绝续期和后续知识调用，停止后台保活，不创建替代任务或绕过鉴权

### Requirement: 源码分析期限绑定原任务
源码分析 SHALL 使用原 Runtime invocation 的执行截止，前置成功搜索 receipt 的单请求截止 MUST NOT 缩短后续源码分析期限。分析开始、读取、占用续期和保存仍 MUST 验证当前任务身份、授权、租约与原截止，不允许跨任务或结束后续用。

#### Scenario: 搜索完成后继续源码分析
- **WHEN** 搜索请求已经完成，其单请求截止已过，但原任务及源码租约仍有效
- **THEN** 允许在原任务期限内继续读取和保存；原任务到期后立即拒绝

### Requirement: 代码答案保存必须可诊断并有界纠正
knowledge_save_code_answer SHALL 在结束源码读取前验证输入结构，失败时返回有界无值参数提示；模型仅可按已取得的真实证据和固定合同有界纠正。保存失败 MUST 保留安全原因，不声称完成入库；保存成功、支持状态及索引就绪 SHALL 分别表达。证据、范围、版本、关键未知项和幂等约束保持有效，不直接索引普通问答记录。

#### Scenario: 无效结构未结束读取
- **WHEN** 保存缺少必填字段或字段类型错误
- **THEN** 返回代码拥有的字段提示，不调用读取结束或远端保存，允许在原任务预算内修正

#### Scenario: 合法保存驱动索引
- **WHEN** supported 答案通过实际读取证据、问题与版本校验
- **THEN** 原子保存正式答案及增量索引任务，Worker 编码并写入对应知识库集合，普通问答记录关联成功答案

#### Scenario: 关键依赖未知
- **WHEN** 分析存在影响结论的未知依赖或矛盾
- **THEN** 保存 partial/conflicted 报告，不建立确定答案索引，不为入库而删改未知项
