## Context

用户确认：默认在线模式逐条核验本人 ONES 当前可读性；本机测试显式启用离线模式，按当前用户和业务应用的知识库权限读取。两种模式均返回来源、入库时间及快照片段，在线失败不降级。当前索引已保存片段与文档修订，可直接用于离线查询。

运行故障同时涉及客户端超时：Runtime 的 Claude Agent SDK 0.2.144 将远程 MCP 配置交给内置 CLI，其 HTTP 首响应默认上限为 60 秒，真实审计三次调用均在约 59.8 秒中止。逐服务 `timeout` 的行为已由实际镜像和合成延迟请求验证，官方说明见 <https://code.claude.com/docs/en/mcp#time-limits-on-mcp-tool-calls>。

## Goals / Non-Goals

目标：由明确部署配置选择在线或离线权限边界，返回入库快照证据；消除 SDK 的默认 60 秒提前中断，同时保留服务预算、取消、Principal 续期及版本一致性约束。

本次不改变采集计划、来源配置、角色授权、检索模型或资源限额，不增加全局超时开关、自动重试或全量文档读取工具。正常 ONES 工具继续遵守原有在线权限。

## Decisions

1. `KNOWLEDGE_ACCESS_MODE` 只由 Knowledge MCP 启动时读取，默认 online，精确接受 online/offline，非法值拒绝启动。主 Compose 默认 online，本机 `.env` 显式 offline。模式只在 Knowledge MCP 执行权限决策，不要求 API/Worker/Runtime 持有同一环境开关，避免多组件配置漂移；模型输入不能切换。目录保持平台 KB 可见性语义。
2. 在线检索先读取本人 ONES 身份元数据，再对重排后的候选逐批调用已有双身份可读性桥（每批至多 10、总计至多 50），核验当前 ONES 详情授权和本人实时可读性；403/404 项过滤，其他错误整体失败。返回前复核本人身份与当前授权，不缓存允许项。离线分支不调用身份读取或 ONES。发布工具仍要求知识目录/搜索成对；在线环境需另外在 Agent/应用选择 ONES 详情工具并授权本人，桥会在使用时强制检查，不自动补权限。
3. 对索引候选完成成员、版本和证据 hash 校验后，在相同来源与知识库范围批量加载当前有效修订的安全元数据。返回前再次校验授权、资源、候选与快照；发生变化则整次失败。
4. 返回完整标题、来源编号、状态、项目、来源更新时间及 `ingested_at`。入库时间不冒充实时采集或来源时间。每文档最多三条有位置和 hash 的文本片段，每条最多 1200 字符；输出实际 `access_mode`，以及固定 `content_mode=ingested_snapshot` 与 `content_scope=matched_chunks`，明确时效和片段范围。不给原始 source_snapshot、attributes、凭据或任意链接。
5. 更新工具输入合同标记与严格输出 schema，总响应上限 512 KiB。旧发布按 schema drift 拒绝；通过正常发布流程更新当前 Agent 和应用，不回写历史发布或 Job。工具合同在两种部署模式下保持一致；模式切换只需重建知识 MCP 容器，不必再次修改发布或数据。首次升级 v4 仍需正常发布。
6. 知识 MCP 的客户端 `timeout` 为 `min(360, Job 剩余秒数) * 1000`，其他 MCP 不变。360 秒来自纯数据合同，避免 Runtime 导入业务模块。服务端绝对截止、Runtime 总超时、取消和在途 Principal 续期仍独立生效；续期不延长截止。canonical 原 120 秒描述显式同步为既有实现的 360 秒。
7. 连接解析、Principal 续期和在线可读性继续使用既有 API 服务身份；平台主密钥和 ONES 凭据不进入知识服务。

## Risks / Trade-offs

- 只有显式 offline 时平台知识库授权才成为内容访问边界，来源侧之后撤权不会逐条映射到离线查询；这是用户明确接受的规则。平台撤权和知识库停用仍即时阻断后续返回。
- 返回的是历史入库片段，不能据此声称当前来源状态或整篇文档内容。片段作为非可信业务数据，不能改变模型指令或工具权限。
- 延长客户端等待不会加快模型，也不代表生产容量或检索质量已通过验收。
- 工作区存在其他未提交改动；仅将已提交代码加本次补丁放入隔离构建上下文，防止顺带部署其他任务。

## Migration Plan

无需数据迁移或重建索引。本机显式 offline，真实环境默认 online，须配置真实 ONES 和本人身份/详情授权。切换模式前等待当前任务完成，再用主 Compose 重建知识 MCP 容器；不在故障时自动改模式。通过知识模块回归、静态检查和 OpenSpec 严格校验后，核对活动任务，重建并更新加载工具合同的服务。验证健康和镜像代码，再用原发布者的现有权限正常发布 Agent、业务应用并激活。真实钉钉请求验收单独记录，不用合成测试代替。

合成传输验证使用无外网、无 Secret 挂载的临时容器：默认配置在 60 秒失败，显式 90 秒配置完成 65 秒调用。取消及截止语义由服务端既有回归验证；未声称额外完成 SDK 取消探针。
