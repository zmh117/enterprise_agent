## 依赖解析

以根 `pyproject.toml` 作为直接依赖来源，明确支持 Pydantic 2.9 及以上的 2.x 版本。Starlette 的兼容范围由同时安装的 FastAPI、MCP 等依赖共同限定。派生镜像安装附加依赖时同时提供基础约束，冲突在构建期报告。独立的知识模型镜像已有按架构锁定的运行时。

## 镜像验收

API 镜像在复制实际应用源码并安装项目后，离线校验已装包的需求，开启管理端功能，调用生产应用工厂并生成 OpenAPI，验证业务应用草稿路由存在。该步骤止于路由及模型装配，不执行连接数据库的应用生命周期。

CI 使用主 Compose 文件中实际存在的服务，双节点 Python Runtime 选择一个代表构建同一目标。通过测试校验服务名和目标的对应关系。
