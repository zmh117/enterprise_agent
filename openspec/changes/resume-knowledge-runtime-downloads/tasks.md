## 验证记录

- 本机 Docker BuildKit 分别构建两个镜像的 `linux/amd64` 和 `linux/arm64` 目标，四次均成功。同架构下第二个镜像命中依赖层缓存。
- 本地 HTTP 服务在 524288 字节处触发读取超时。pip 以 `Range: bytes=524288-` 恢复下载并安装。服务端忽略 Range 时重新下载成功，哈希错误和恢复次数耗尽时均以失败退出。
- 五个相关测试文件共 122 项通过。另有一个 Knowledge MCP 镜像白名单测试失败，在修改前的 HEAD 上复现了同样的错误。该测试只复制子阶段中的文件，遗漏了父阶段提供的浏览器扩展协议文件。
