## Decisions

构建安装器采用单独的带哈希锁文件。现有模型 profile 对运行时锁文件的原始字节计算摘要，把构建工具写入该锁会改变现有模型身份。

两个 Dockerfile 使用相同的安装指令和 BuildKit 缓存。依赖读取超时设为 120 秒，连接重试和中断恢复各最多 5 次。服务端支持 HTTP Range 时由 pip 从已接收位置继续；不支持 Range 时允许重新下载，安装前仍须通过原始哈希校验。

## Verification

在本地 HTTP 服务中故意中断一次 wheel 传输，检查下一次请求的 Range、安装结果和错误哈希拒绝行为。验证两种目标架构的镜像构建及已有模型相关测试。
