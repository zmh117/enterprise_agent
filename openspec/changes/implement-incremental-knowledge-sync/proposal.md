## Why

当前小时同步按 run 创建完整候选 collection，少量新增也复制、校验全部旧向量；发布摘要又绑定全库成员与内容，使内容更新必须重新发布。用户已明确发布只表示知识库可用，授权实施固定集合、文档增量更新和持久断点恢复。

## What Changes

- **BREAKING**：发布仅冻结来源、连接、模型与分块配置，不冻结内容成员、数量、语料摘要或采集 run。
- 同一知识库使用固定 collection；只处理新增或修改的文档，独立生效并清理其旧向量。
- 采集、发布和文档处理状态分离；恢复只补做未完成步骤，部分失败不撤回成功文档。
- 移除受管同步热路径的整库候选复制、向量搬运及完整性扫描；保留显式维护检查。
- 检索继续执行当前 KB 授权与 ONES 个人可读校验，只检查命中文档的当前版本。
- 提供显式一次性迁移入口；保留现有数据和已验证向量，不自动操作目标部署。
- 在线增量采集同时间戳内容不同直接接受本次内容为新修订，保留历史与旧版本防回退；记录安全结构化日志，不追加二次详情请求。

## Capabilities

### New Capabilities

无新增 canonical 领域。

### Modified Capabilities

- `platform-operations`：受管同步改为固定索引与文档处理断点，替换整轮原子发布合同。
- `builtin-tool-resource`：资源发布与动态内容解耦，保留权限与配置变化的失败关闭。

## Impact

影响 knowledge 同步、索引、资源配置、检索证据、清理、CLI、schema migration 与测试。复用现有 PostgreSQL/Qdrant/Embedding，保持在线 Embedding 隔离，不新增消息队列，不修改 ONES Provider 日期过滤合同，不自动启停生产服务或提交代码。
