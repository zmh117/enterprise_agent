# Spec Delta

## ADDED Requirements

### Requirement: 已连接的浏览器插件可以切换账号

插件与平台 SHALL 允许用户为插件重新输入系统账号，确认连接后按该身份重新加载数据。平台网页已有的登录会话 SHALL 保持原身份。

#### Scenario: 已同意连接后换用另一个账号

- **WHEN** 用户从连接设置切换到账号 B 并确认授权
- **THEN** 当前插件页面及已打开的其他插件页面按 B 的权限显示应用、会话及站点范围，重新打开时仍按 B 连接
- **AND** 原账号的持续采集停止，其待传数据仍归原账号

#### Scenario: 用户输错密码或取消换号

- **WHEN** 用户输入错误密码后取消或关闭授权窗口
- **THEN** 插件保留当前账号的连接，用户可以再次切换

#### Scenario: 同时请求浏览器授权

- **WHEN** 一个插件页面正在交互授权，另一个页面或后台请求静默授权
- **THEN** 插件串行调用浏览器授权 API，被取消的排队请求不得恢复旧账号
