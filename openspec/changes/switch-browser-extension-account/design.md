# Design

## Context

控制页、浮窗和持续采集各自持有短时访问凭据。浏览器的身份授权窗口由整个插件共享。

## Goals / Non-Goals

用户可以在同一浏览器配置中切换插件账号。平台管理网页继续使用自己的会话。

## Decisions

- 账号密码只在平台授权窗口输入，沿用登录限速及 PKCE。切换成功后使用绑定到系统来源的插件专用父会话续期。
- 切换期间保留当前连接，用户确认后发布新身份并重新加载页面。沿用现有的按来源与账号隔离的记录和投递队列。
- 用同一把 Web Lock 协调交互授权及静默续期，保留浏览器自身的授权窗口生命周期。

## Risks / Trade-offs

切换入口需要目标环境的 API 与新版插件配套。测试需覆盖 HTTP 和 HTTPS，以验证已有网页会话及插件续期身份。
