## ADDED Requirements

### Requirement: SVN 目录预览按层加载并固定浏览身份
代码知识库管理页面 SHALL 首次只加载当前目录的直接文件和文件夹，展开子目录时才查询该层；MUST NOT 为预览根目录递归列出整个分支。所有子层请求 MUST 复用同操作者、同资源当前草稿的成功根浏览操作中固定的连接、仓库和数字 SVN 修订，服务端校验路径和连接身份。目录清单继续使用有界临时结果，不持久化完整树、不静默截断。页面 SHALL 保留文件/目录多选与同层对齐，父项选择涵盖未展开子项，提供局部加载、失败重试和明确超限提示。

#### Scenario: 大分支首次浏览
- **WHEN** 分支完整清单超过单次 XML 上限，但根目录直接子项未超限
- **THEN** 根预览成功且不读取后代清单，文件夹可按需展开

#### Scenario: 浏览期间发生新提交
- **WHEN** 首次浏览固定 N 版本，之后 HEAD 增长并展开子目录
- **THEN** 子目录与检出仍使用 N 版本，不能混入新版本目录项

#### Scenario: 伪造浏览身份或目录
- **WHEN** 子层请求引用另一操作者、另一资源、旧草稿、非根或失败的浏览，或目录越界
- **THEN** 拒绝且不连接 SVN；执行前再复核当前连接与配置

#### Scenario: 子目录失败及重新浏览
- **WHEN** 单层响应超限、预览过期或连接失败
- **THEN** 页面显示明确失败和局部重试，保留其他目录选择；重新浏览后旧响应不能进入新树
