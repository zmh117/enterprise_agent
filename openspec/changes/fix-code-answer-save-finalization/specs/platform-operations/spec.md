## ADDED Requirements

### Requirement: 源码分析必须记录独立知识保存结果
标准回答收尾 SHALL 在已有分析记录中保存独立 knowledge_save 元数据，区分已保存、已保存部分或矛盾分析、保存失败、未提交保存服务、未就绪和结果未确认，包含有界服务端尝试次数与固定安全错误码。保存服务 SHALL 在安全请求摘要保留 analysis_id，以明确关联分析，不按审计落库时间猜测。该状态 MUST 不改变业务回答成功、索引任务统计或证据准入；不复制工具正文、源码或凭据。

#### Scenario: 保存失败但回答成功
- **WHEN** 分析未生成答案且保存工具已失败
- **THEN** 业务回答继续保存，分析元数据记录失败和安全错误码，索引任务不虚增

#### Scenario: 从未调用保存
- **WHEN** 已取得源码读取资格的分析结束而没有保存调用
- **THEN** 明确记录未提交保存服务，不用 cancelled 状态掩盖保存未执行；本地参数拒绝由 Runtime 审计记录

#### Scenario: 证据不足
- **WHEN** 工具成功保存 partial/conflicted 分析结果
- **THEN** 记录已保存但不可索引，不误报保存失败、不建立确定答案向量
