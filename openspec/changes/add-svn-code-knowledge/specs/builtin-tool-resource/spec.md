## MODIFIED Requirements

### Requirement: 知识资源与固定目录检索必须执行当前双重授权
系统 SHALL 通过已验证、已发布且当前启用的知识资源提供读取。ONES 来源 SHALL 使用代码固定 `knowledge_list_bases`、`knowledge_search`；Knowledge MCP MUST 验证自身 audience/scope、RUNNING Job、冻结工具合同、当前用户/应用/角色 KB 范围及资源发布事实，检索命中 MUST 再校验当前用户 ONES 可读权限，目录可见不得解释为所有工作项可读。SVN 代码知识 SHALL 使用独立的固定代码知识工具及当前角色知识库范围，无需用户 SVN 或 ONES 身份，不得把此分支用于绕过 ONES 的个人可读性检查。新工具、收录、索引和目录变化 MUST NOT 自动扩大旧 Publication 或 Job 权限。

#### Scenario: 发现当前知识库
- **WHEN** 当前 Job 获准调用 ONES 知识目录
- **THEN** 每页最多返回 50 个当前可用知识库的安全身份、名称和状态，提供有界续页，不返回正文或文档计数

#### Scenario: 授权或发布事实变化
- **WHEN** 用户/应用/角色 KB 权限撤销、资源停用或发布配置改变
- **THEN** 目录或检索失败关闭，不回退旧授权继续返回；代码知识已授权的自动内容更新遵循当前读取批次合同，不改变用户权限

#### Scenario: 来源事项不可读
- **WHEN** ONES 向量候选对应事项未通过当前用户 ONES 可读性校验
- **THEN** 不返回该事项引用，也不以服务账号或知识库授权代替个人权限

#### Scenario: 代码知识读者没有 Provider 身份
- **WHEN** 当前用户满足应用、代码知识 Tool 与知识库角色范围，但没有 SVN 或 ONES 个人身份
- **THEN** 允许继续执行代码知识读取及新鲜度检查，不要求补充 Provider 身份

## ADDED Requirements

### Requirement: 代码知识必须提供固定有界目录当前查询和变化查询工具
系统 SHALL 注册 `code_knowledge_list_bases`、`code_knowledge_search`、`code_knowledge_changes` 为 `knowledge-mcp` 的只读 Tool，按各自 schema、scope 与来源类型校验。当前查询 MUST 接收明确知识库、1–2000 字符 query、默认 5 且最多 20 的 top_k；目录和变化查询每页最多 50 项，响应最多 256 KiB，并遵守最多 120 秒及 Job 剩余时间的共享预算。参数 MUST NOT 接受 URL、Shell、凭据、任意过滤条件、源码路径读取指令或用户选择的 revision。

#### Scenario: 查询当前业务规则
- **WHEN** 合法查询命中若干代码衍生规则
- **THEN** 返回结构化业务事实、必要条件/例外、表字段、覆盖状态和安全业务引用，不返回源码引用位置或原始实现

#### Scenario: 请求错误来源或任意代码读取
- **WHEN** 用户将 ONES 库交给代码知识 Tool，或注入 URL、revision、Shell、源码读取参数
- **THEN** 固定合同拒绝请求，不切换到通用代码工具或另一来源权限路径

#### Scenario: 目录显示正在建立基线
- **WHEN** 角色获准的代码知识库仍在建立基线或更新
- **THEN** 目录可以返回安全就绪状态，内容查询仍必须执行新鲜度合同，目录可见不代表内容已可回答

### Requirement: 当前代码知识查询必须确认最新目标并有界等待
内容查询 SHALL 先鉴权，再通过受信平台 bridge 确认服务端 SVN HEAD 操作修订号并固定本次目标。工作副本版本、last-changed 和轮询缓存 MUST NOT 代替本次确认。系统 SHALL 等待完整扫描及连续已应用位置达到目标，探测、等待、检索与读取共用 deadline。超时 MUST 返回明确的暂不可用错误；无法确认 SVN 目标、来源停用或分析依赖失败不得降级为旧知识或零命中。

#### Scenario: 新提交尚未完成知识更新
- **WHEN** 目标提交已经存在但知识水位尚未追上
- **THEN** 在预算内等待更新，完成后读取完整当前结果；超时返回 `code_knowledge_not_ready`

#### Scenario: SVN 无法访问
- **WHEN** 本次查询不能确认服务端最新目标
- **THEN** 返回 `code_knowledge_source_unavailable`，不使用上次成功结果证明最新

#### Scenario: 等待期间出现更多提交
- **WHEN** 查询已固定目标而主干继续更新
- **THEN** 不无限提高本次等待目标，后续提交由下一次新查询处理

#### Scenario: 未追上时聊天记录有旧答案
- **WHEN** 最新查询失败但当前会话含有此前返回的规则
- **THEN** Agent 只说明最新知识暂不可用，不重述旧规则冒充本次最新结论

### Requirement: 一次知识回答必须使用一致读取批次且保留完整规则
系统 SHALL 在满足最新目标后为本次 Job invocation 与知识库建立短期服务端读取上下文，固定实际读取批次及时间轴上界；同次回答的搜索和分页 MUST 保持一致并复核当前授权，不能由用户选择内部批次。上下文到期 MUST 明确失败，不无声切换。召回片段 SHALL 回表装配完整规则及必要例外，不得通过截断条件满足响应预算。

#### Scenario: 查询过程中后台再次激活
- **WHEN** 已建立读取上下文后出现新的当前知识批次
- **THEN** 本次回答继续读取受保护的一致批次，正文、成员关系与索引均保持可读，时间轴使用同一上界；下一次新查询取得新目标，回收不得删除仍被读取的内容

#### Scenario: 规则超出返回预算
- **WHEN** 规则的必要条件、例外或关联无法完整装入有界响应
- **THEN** 返回结果过大或需缩小问题的安全提示，不返回缺条件的成功结论

#### Scenario: 所问结论依赖未解析逻辑
- **WHEN** 匹配主题存在会影响本问题的未解析调用或配置
- **THEN** 返回 `code_knowledge_analysis_incomplete` 或明确限定的已证实部分，不用模型猜测补齐

### Requirement: 业务变化查询必须明确连续覆盖和时间含义
变化 Tool SHALL 接受明确知识库、可选主题、带时区的时间范围及受绑定游标，返回基线覆盖起点、同主题前后业务事实、影响和提交/分析时间。分页 MUST 绑定当前用户授权、知识库、查询条件和读取上界，保持稳定提交顺序。未收录区间、处理缺口、有界部分结果和无事件 MUST 分开表达；内部 revision 用于排序和证据，不作为产品知识版本入口。

#### Scenario: 查询一个月内规则演变
- **WHEN** 该范围在已收录且连续处理范围内并发生多次规则调整
- **THEN** 按提交次序返回关联同一主题的变化与前后事实，包含已核实的恢复行为，不只返回最终净差异

#### Scenario: 查询跨越接入时间
- **WHEN** 查询时间起点早于基线而终点位于基线之后
- **THEN** 明确前半区间未收录，只对已覆盖部分给出事件，不把空白部分解释为没有变化

#### Scenario: 游标被跨库或跨用户重放
- **WHEN** 调用者改变知识库、用户、筛选条件或授权后重用游标
- **THEN** 拒绝续页，不能读取原游标范围的历史内容

### Requirement: 代码知识输出允许结构元数据但不得交付源码
在线 Tool、最终回答、引用、附件、错误和用户可见审计 SHALL 只使用经过发布检查的业务投影。系统 SHALL 允许表名、字段、类型、约束、关系和有证据的业务含义；MUST NOT 返回源码正文、原始 diff、源码附件/下载链接、凭据、原始 SQL/DDL 或私有实现证据。不得通过编码、分段、多轮引用或附件绕过该边界；任何角色授权都不授予这些工具源码读取能力。

#### Scenario: 用户询问表字段
- **WHEN** 有权用户询问状态字段的类型、含义和相关业务条件
- **THEN** 返回结构元数据与实现支持的业务解释，不因包含字段名而拒绝，也不附带实际源码

#### Scenario: 用户要求源码或编码后的实现
- **WHEN** 用户要求查看实现、逐行翻译源码、返回 base64 diff 或下载源码文件
- **THEN** 不提供受保护内容，只能在现有授权范围解释业务规则；问答模型没有可绕过的源码 Tool
