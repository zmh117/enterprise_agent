## 1. 实施准备与独立验收样例

- [ ] 1.1 核实首批 C++ 编译方言/宏/头文件与编译数据库、Vue 主版本及 JS/TS 形态、Java 版本/框架/持久化形式；记录实际支持范围与不支持边界，不预设 Spring 或某个 Vue 主版本。
- [ ] 1.2 根据三类实际代码形态锁定 SVN 客户端、Clang、Vue/JS/TS 与 Java 解析依赖及许可证，定义受限参数与输入/运行预算；验证解析过程不执行仓库安装、构建或插件命令。
- [ ] 1.3 建立 C++、Vue、Java 的最小合成业务仓库及人工确定的预期规则，覆盖错误注释、公共方法限制、条件编译、前端/后端差异、动态调用缺口和跨层契约；预期不得由待测分析模型自己生成。
- [ ] 1.4 明确目标 SVN 连接、允许路径、源码分析模型连接和 hook 配置条件的登记方式；仅使用受管连接/Secret 引用，在接入真实仓库前完成来源范围与源码处理环境核实。

## 2. 数据结构与来源治理

- [ ] 2.1 在既有知识模型中增加 `svn_code` 来源、同平台内容绑定与配置修订，沿用 source/document/知识库收录，避免伪装成 ONES 工作项。
- [ ] 2.2 增加基线位置、发现/完整扫描/已应用水位、提交处理记录、持久阶段、单来源租约和 fencing 约束，验证 revision 去重及前驱顺序。
- [ ] 2.3 实现当前业务/表字段事实、稳定主题、业务变化事件及分析纠正记录；保证重复重放幂等，当前视图与历史事件分别查询。
- [ ] 2.4 隔离私有源码证据/依赖和可发布投影的存储访问，收紧在线数据库账号权限；验证 MCP 无法直接读取私有证据或源码内容。
- [ ] 2.5 通过现有 Migrator 编写迁移，更新 schema 注释、事实源清单和 SQLite 等价对象；验证保留既有 ONES、角色与 Job 数据，在线服务不执行 DDL。

## 3. SVN 采集与连续同步

- [ ] 3.1 实现固定参数的只读 SVN 适配器和允许路径筛选，禁用 externals、越界链接、任意命令及凭据参数/认证缓存泄露；读取服务端操作 revision 而非 last-changed。
- [ ] 3.2 实现首次固定 `R0` 的来源清单与基线任务，失败在相同目标恢复，基线构建期间继续登记后续提交。
- [ ] 3.3 实现默认 60 秒的可配置定期补扫，固定扫描上界、有界分页、范围内相关提交发现及对无关 revision 的完整扫描证明；无待处理相关提交时推进已应用证明位置而无需重建索引。
- [ ] 3.4 实现已鉴权的轻量 post-commit 接收入口及部署说明；通知只登记线索并唤醒任务，回源核实，重复/乱序/遗漏均由去重与补扫收敛。
- [ ] 3.5 实现单来源顺序处理、持久阶段重试和租约接管，失败提交不被跳过，失效 worker 无法激活迟到结果。
- [ ] 3.6 实现来源身份/范围/配置变化、权限不足、历史不可达、主干根替换和同步停用的安全失败路径；不把读取失败解释为无变更或擅自重建基线。

## 4. 可执行代码分析与事实核验

- [ ] 4.1 实现 C++ 解析：函数/类、调用、分支、枚举、状态及数据读写，绑定批准的编译上下文；未解析宏、include、动态分派和多目标条件保留缺口。
- [ ] 4.2 实现 Vue 解析：匹配实际版本的 SFC/template 与 JS/TS、事件、计算状态、表单校验、路由和请求封装；明确前端限制不能代替后端校验。
- [ ] 4.3 实现 Java 解析：类型/接口、实际注册入口、调用、条件、异常和持久化；针对首批实际框架实现明确识别规则，未知反射/注入不猜测。
- [ ] 4.4 实现有界入口探索与调用/数据依赖收集，按可核实 HTTP/消息/调用契约关联三类代码，公共方法和上游限制进入业务事实上下文。
- [ ] 4.5 实现源码处理模型的独立配置与结构化候选生成，逐条绑定提交和证据；排除注释/提交说明独立作证，保留条件组合、单位、边界、例外及异步完成区别。
- [ ] 4.6 实现表字段知识提取与冲突检查，区分迁移/映射、物理外键/逻辑关系、代码定义/生产事实，字段语义由读写逻辑支持。
- [ ] 4.7 实现证据摘要、可达性、条件/结果、缺失调用和输出允许字段核验；模型置信度不作通过条件，超预算及不确定结论以安全缺口表达。
- [ ] 4.8 实现源码、原始 SQL/DDL、diff、敏感片段、编码内容与下载链接的发布检查；未通过候选不得进入业务正文或向量，错误摘要不携带原始内容。

## 5. 当前知识与业务变化时间轴

- [ ] 5.1 实现稳定主题/事实匹配，覆盖文件移动、重命名与主题标题调整；无法可靠合并的关系显式待确认，不凭模型相似度覆盖无关规则。
- [ ] 5.2 根据每个提交及依赖范围重新分析前后事实，生成新增/修改/删除事件；公共依赖变更扩大影响范围，无法限定时扩大分析或失败。
- [ ] 5.3 实现无业务变化提交的处理记录与索引复用，以及连续改变/回滚的独立事件；纯格式/注释变化不能制造业务事件。
- [ ] 5.4 保存基线覆盖起点、提交时间与分析时间，稳定处理相同或倒退时间，区分分析纠正与代码变化；实现接入前未收录提示和代码行为非上线事实标识。

## 6. 候选索引与原子激活

- [ ] 6.1 增加保留规则条件/例外的业务分块与当前知识索引，复用后台 Embedding 路由；搜索片段必须回表装配完整规则。
- [ ] 6.2 实现不可见候选准备和索引验证，再以同平台短事务提交当前事实、事件、活动索引引用与已应用水位；不依赖跨 PostgreSQL/Qdrant 事务。
- [ ] 6.3 实现激活前来源配置、资源绑定、启用状态、分析 profile、租约和前驱水位复核；技术失败与未知影响范围阻止进度推进，受影响旧规则不得继续冒充最新。
- [ ] 6.4 实现幂等恢复及共同保护旧批次正文、成员与索引的短期读取租约，再按引用清理候选和旧批次；保留业务时间轴，不提供用户选版、内容回滚或逐提交人工发布。

## 7. 在线固定工具与最新读取

- [ ] 7.1 注册三个代码知识 Tool 的 Manifest、schema、scope、中文说明、只读 effect、输出大小与分页合同，保持既有 ONES Tool schema 不变。
- [ ] 7.2 实现代码知识目录、完整业务事实查询和主题时间轴查询，限制来源类型及输入字段；规则过大时明确失败，不能截断必要条件。
- [ ] 7.3 实现双身份 freshness bridge，鉴权后按已登记来源确认 SVN HEAD，元数据探测与后台分析槽位分开；调用方无法覆盖 URL、命令、凭据或源码路径。
- [ ] 7.4 实现固定查询目标、扫描/应用双水位等待、共享最多 120 秒且受 Job 剩余时间限制的 deadline、取消与错误分类；不返回旧知识或伪造零命中。
- [ ] 7.5 实现 Job invocation/知识库绑定的短期一致读取上下文与游标，同一回答固定正文批次和时间轴上界；超时/失效明确终止，不无声换批。
- [ ] 7.6 更新 Agent 的代码知识使用指引与运行提示，要求新的当前问题检查新鲜度；最新查询失败时不从旧会话结果回答，实际业务对象数据继续使用独立授权工具。
