# Spec Delta

## Purpose

保证页面、语义、请求、错误和导出内容遵守冻结策略。按 2026-11-17 用户明确决定，默认仅保护登录密码，其他文本、输入、URL 和请求头原值保留；额外敏感区域仅在用户手动配置时生效。历史验收按当时策略解释。

## ADDED Requirements

### Requirement: 默认仅保护登录密码

系统 SHALL 默认保留普通页面文本、DOM 属性、输入、URL 参数、Cookie、Bearer/JWT、令牌及正文业务字段，不执行通用文本或凭据掩码。系统 MUST 保护密码输入、密码 autocomplete、明确 password/passwd/pwd/pass 等密码字段，以及 HTTP Basic 中的密码。通用掩码配置默认关闭，策略版本随包记录。

#### Scenario: 普通值与密码同时出现
- **WHEN** 页面和接口同时包含普通输入、令牌、认证头、查询参数及登录密码
- **THEN** 普通值原样保存，密码不能出现在桥接业务消息、数据库或导出正文中
- **AND** 密码输入切换为显示密码后仍保持保护，域名授权、预算和 STOP 边界不放宽

### Requirement: 敏感区域规则覆盖全部语义字段

用户显式配置额外敏感选择器时，系统 SHALL 将该规则应用于区域内的值、文本、标签、业务属性和上下文字段。命中显式选择器的元素即使具有普通 `data-*` 属性，也不得将其原值跨采集桥转发、持久化或导出。默认不因 data-sensitive 属性屏蔽内容。

#### Scenario: 敏感容器包含普通名称的业务属性
- **GIVEN** 一个容器命中敏感选择器，其子控件的 `data-value` 包含没有 token/password 前缀的测试秘密
- **WHEN** 用户点击或程序修改该控件
- **THEN** 语义目标、状态和上下文均不含原值，保存内容使用掩码或排除状态，合法结构引用仍然完整

#### Scenario: 允许字段位于敏感区域
- **WHEN** 字段名在允许名单内，但控件位于已标记敏感区域
- **THEN** 敏感区域规则优先，该字段不能因允许名单而输出原值

### Requirement: 脱敏失败和无效规则不可回退到原文

系统 SHALL 检查策略可执行性。选择器无效、正文无法解析或脱敏过程失败时，必须拒绝启动受影响采集或明确排除内容并显示原因，不能回退到未处理原文。其他不受影响且安全的通道可以继续。

#### Scenario: 配置无效选择器
- **WHEN** 用户提交语法错误的敏感选择器
- **THEN** 界面给出可定位的配置错误，受影响的页面采集不开始，不显示页面已就绪

#### Scenario: JSON 正文无法安全处理
- **WHEN** 正文不是合法 JSON 或超出可安全脱敏的预算
- **THEN** 正文状态为排除并给出原因，不创建虚假的 bodyRef，不保存残缺 JSON 或原文

### Requirement: 各通道独立执行允许和掩码策略

系统 SHALL 在持久化前分别对 DOM 属性、URL、语义、请求与响应头、正文、console、异常和启用的流消息执行密码保护及显式配置规则。普通认证令牌、精度、业务 ID 和版本保持原值；策略及实际排除范围随包保存。

#### Scenario: text/plain 与 XSSI JSON 正文
- **WHEN** 已允许接口的正文处于预算内，类型为 text/plain 或带精确 XSSI 前缀的 application/json
- **THEN** 系统 SHALL 对可解析 JSON 的密码字段进行保护，普通文本仅处理明确密码标注并保留其他原值，原 Content-Type 保留
- **AND** 超限或无法完整解析的 application/json 明确排除，不执行脚本包装或输出残缺 JSON


#### Scenario: 同一密码出现在多个通道
- **WHEN** 同一测试密码以明确密码字段出现在 DOM、URL 属性、接口、console 对象预览和流消息中
- **THEN** 检查数据库和解压包均不能找到密码原值，普通令牌仍可找到，各通道分别有对应证据

#### Scenario: 保留合法业务精度
- **WHEN** 普通字段值为 `3.00`，同一对象另含密码与令牌
- **THEN** 业务值仍为 `3.00`，令牌保留原值，密码使用明确掩码，不伪装为空字符串或未发生输入

### Requirement: 截图停用是显式能力限制

系统 SHALL 在不能保证像素脱敏时停用截图，并在策略、标记结果、预览和问题包中使用一致的停用原因。停用时不得执行任何截图读取，不得使用当前活动窗口截图或主动切换标签来填补缺失。

#### Scenario: 停用策略下标记后台目标
- **WHEN** 用户对后台已纳入目标标记问题，同时切换到未纳入标签
- **THEN** 不执行截图，标记记录截图 unavailable/停用原因，其他页面状态证据仍可保存
- **AND** 验收记录将截图执行路径标为该策略下不适用，不标为已验证的截图能力
