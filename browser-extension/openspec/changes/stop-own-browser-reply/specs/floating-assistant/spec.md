# Spec Delta

## ADDED Requirements

### Requirement: 发起人可以停止当前回答

阅读浮窗与插件控制台 SHALL 在提交问题后把发送按钮切换为「停止回答」。普通用户仅可停止自己从插件发出的本轮任务。插件 SHALL 将停止意图提交给平台，并以服务端确认的任务终态恢复发送。正在输入的下一条消息保留为草稿。

#### Scenario: 在取得消息回执前点击停止

- **WHEN** 用户发送问题后立即点击停止，此时插件正在等待任务标识
- **THEN** 插件在取得该次提交的回执后向平台请求取消对应任务，提问只提交一次

#### Scenario: 停止与完成同时发生

- **WHEN** 用户点击停止时该任务已经完成
- **THEN** 插件显示服务端已完成的回复，恢复发送按钮并保留下一条草稿

#### Scenario: 回答期间编写下一条消息

- **WHEN** 用户在运行中的回答下输入追问草稿，并在输入框按 Enter
- **THEN** 草稿保留，当前任务继续执行，插件等待用户显式点击「停止回答」

#### Scenario: 服务端正在停止任务

- **WHEN** 平台已接受取消请求，原任务仍在执行
- **THEN** 按钮显示正在停止并防止重复点击，任务确认终态后恢复发送，输入框中已有的草稿保留
