# 系统登录与流式回答联调

2026-11-19，本机 Enterprise Agent 管理台和插件业务接口共用 HTTP 端口 8080，数据库迁移至 163。「插件联调」应用仅向专用测试账号开放，复用平台已有模型，提问内容为虚构的 Markdown 表格。

| 场景 | 观测结果 |
| --- | --- |
| 首次登录与静默登录 | 将 agent-qa.test 在独立 Chrome 内解析至回环。第一次点击登录后在原生授权窗口完成系统登录与同意，返回插件能选中应用。重开后通过非交互授权取得凭据。 |
| 真实模型首段与续读 | 首轮仍在生成时已显示 73 个字符。模拟浏览器离线并中断订阅，恢复后从游标 24 续读，最终显示 18 行表格。重开控制台的 HTML 与终态一致。 |
| 连续提问 | 两次提交各获一个成功 Job，属于同一会话。数据库分别记录 25 批和 4 批可见正文。 |
| 撤权 | 专用账号原可见 1 个应用。暂时撤销业务角色后列表为空，原 Job 快照由 200 变成 404；恢复该角色后重新可读。 |
| 从生成中的 Job 关闭再重开 | 独立 Chrome 搭配实际 Nginx 配置及合成 Worker，首段和空闲心跳均穿过代理。断线并跨凭据过期后续读，在 Job 尚未完成时关闭控制台，重开仍取到同一 Job 的最终 Markdown。 |

跨仓复跑在本仓库执行 `npm run check`，然后执行 `EA_TEST_NGINX=1 node tests/agent-stream-browser.mjs`。测试使用本机缓存的 nginx:latest、Playwright Chromium 及相邻服务端仓库。预授予测试副本回环主机权限；原生 Chrome identity 处理登录及非交互授权。该次文字联调覆盖本机 HTTP。大录制、工具检索及跨协议测试的结果见下文。

## 首问已受理且回执正文中断

独立 Chrome for Testing 加载实际插件构建，经临时 Nginx 连接合成平台。服务端受理首问后，测试代理将 HTTP 202 的 JSON 回执截断。关闭控制台前，本地记录只有待确认消息的 ID、原会话与应用范围，历史 Job 数为零。重开控制台后，插件以原消息 ID 查询回执，取得原 Job 并开始显示回答。此次只发送一次提问 POST，数据库最终只有一个 Job。

同一轮回答中断开 SSE 并使凭据过期，插件自动续期。代理记录的订阅游标依次为 1、4、4、6，收到了一个空闲心跳。执行期间关闭再重开控制台后，最终 Markdown 与终态快照一致，界面只出现一份回答。此轮使用可控合成 Worker。

## Chrome 实际构建共享录制并连续提问

在只解析至回环的 `agent-qa.test` 上，分别通过带自定义端口的 HTTP 和 HTTPS 首次登录。HTTPS 使用仅在独立测试 Chrome 中受信的临时证书。Nginx 后方运行合成应用及真实 File Service 和一次性 MinIO。测试副本已预授予访问该测试主机的权限。

两次都从超过 100 MiB 的合成录制得到 3 条请求、1 条操作。源有 4 条请求，其中 1 条为插件平台请求。预览显示的 1,051,694 字节为未压缩 NDJSON，实际两个 PUT 的 gzip 正文共 2,101 字节。第 0 片回执被截断后关闭控制台并让凭据过期。重开确认同一录制时仅上传第 1 片。原清单按规范序列化后比较，Chrome 存储调整 JSON 键的次序也能恢复。

受控执行器依次定位保存操作附近的失败请求、按同一证据 ID 查业务码、用已有会话历史总结。一次发布，四条索引，三轮三条 Job。后两问共享数据上传量为零。首问 SSE 在 Markdown 中途断流，静默换证后继续读取，最终 HTML 与快照恢复一致。两种来源的订阅游标均为 1、4、4、6。

HTTP、HTTPS 的源对象序列化大小为 107,320,401 和 107,320,402 字节。两次投影均缩小约 99.02%。样本使用高度重复的回放及业务字段，数据压缩率随内容而变。初次预览至上传中断时对控制台渲染器采样，JS 堆峰值分别为 49,971,048 和 39,429,120 字节。当时仅采样渲染器 JS 堆，进程 RSS 结果见下文。本机目标平台上的真实模型验收见下节。

`npm run check` 通过类型检查、70 项测试和解压构建。跨仓复跑分别运行 `EA_TEST_NGINX=1 EA_TEST_RECORDING=1 EA_TEST_ORIGIN=http-host node tests/agent-stream-browser.mjs` 和 `EA_TEST_NGINX=1 EA_TEST_RECORDING=1 EA_TEST_ORIGIN=https-host node tests/agent-stream-browser.mjs`。依赖已安装的 Playwright Chromium、OpenSSL、本机缓存的 nginx:latest 和 minio/minio:RELEASE.2025-04-22T22-12-26Z。

## 2026-11-20 本机 8080 大录制与真实模型

在独立 Chrome 中加载插件构建，预授予测试副本回环主机权限。通过原生身份窗口用临时系统账号在 HTTP 平台登录并选择「插件联调」。平台数据库版本为 164，应用允许真实模型按需检索和读取录制。运行两次独立三轮问答，以下数值来自带有上传与回答双重中断的第二次验收。

1. 选择包含超过 100 MiB 合成回放的录制并确认共享。4 条源请求中排除 1 条平台请求，服务端建立 3 条请求和 1 条操作索引。分片展开共 1,401,737 字节。第 0 片已提交后，驱动丢弃回执并使访问凭据过期。恢复时收到 401，插件静默换证，继续上传第 1 片。两个实际 PUT 的 gzip 正文为 1,413 和 1,038 字节，完成提交一次。
2. 首问定位失败请求。界面显示 47 个字符且仍为「回答中」时断开 SSE、使凭据到期。恢复联网后插件处理 401 并静默换证，从原 Job 的游标 5 继续显示 Markdown。
3. 在两个 Runtime 节点确认首问沙箱均已回收后追问。模型按同一证据 ID 读出只存在于明细中的随机业务码和批次标签，第三问通过会话历史总结。平台分别记录一次搜索、一次读明细和零次工具调用。
4. 三问只提交三个成功 Job，属于同一会话，后两问上传录制共 0 字节。逐轮拼接 14、21 和 5 批正文均等于持久助手消息。重开控制台后，三个回答的 HTML 均与断线恢复后的终态相同。

两个临时用户已停用，独立 Chrome 配置已清理。本次使用本机 HTTP 地址，跨机器网络没有在这次测试中实测。

## 2026-11-20 回执过期、换号与实际采集

目标使用 `http://agent-qa.test:8080`，由独立 Chrome 解析到本机现有平台。首问已受理后丢失回执，重开按原消息查询时触发凭据到期，恢复同一个 Job。分片 0、1 各上传一次。界面先显示 29 个字符，断线换证后从游标 4 续读。三个成功 Job 属于同一会话，追问上传录制共 0 字节。父会话到期后显示重新登录提示，原账号登录后，三个回答的 Job 标识和 HTML 完全一致。

在独立 HTTP 平台使用合成执行器验证半段回答时换号。旧草稿清空，另一账号可见旧回答数为零。原账号再次登录时，已经结束的 Job 通过终态快照恢复。跨来源业务重定向的接收端得到零次请求。Chrome 实际采集网页点击与接口后，通过控制台预览、确认共享并查询失败请求、业务码和附近点击。对独立采集、保存和离线 ZIP 的回归包含 23 项检查。合成平台凭据标记在录制、页面消息、扩展存储及 ZIP 中均没有出现。

大录制有 4 条源请求、1 条源操作，排除 1 条平台流量，发布 4 条索引。源对象 107,320,425 字节，投影 1,051,976 字节，两个 gzip 分片正文合计 2,202 字节。预览至续传完成期间共采样 33 次，独立 Chrome 中标为扩展进程的渲染器 RSS 合计峰值为 279,396,352 字节。整套独立 Chrome 的 RSS 合计峰值为 980,107,264 字节。该指标可能重复计算共享页，且受合成样本与采样间隔影响。

复跑使用 `npm run check`、`npm run test:p0` 和 `EA_TEST_RSS=1 EA_TEST_SIGNIN_RECOVERY=1 EA_TEST_CAPTURE=1 EA_TEST_NGINX=1 EA_TEST_RECORDING=1 EA_TEST_ORIGIN=http-host node tests/agent-stream-browser.mjs`。本期平台接入和目标验收范围为内网 HTTP。先前隔离环境的 HTTPS 数据保留为历史测量。

补测同一 8080 目标。两仓共用的第 A 版样例在范围变更和清单冲突时分别得到 409。暂存到期后，旧初始化、迟到的分片和完成请求均为 410。新版本完成后可复用。在解压测试副本中实际点击合成页面的保存按钮，再从控制台确认共享，真实模型查到了失败请求、业务码与附近点击。两次目标验收的临时用户均已停用。

目标 HTTP 另测回调与半帧。合成错误 state 在发起兑换前即被拒。旧账号兑换响应延迟至另一账号完成登录才返回，旧请求被取消。真实回答在首个正文帧中途断开后，插件按最后完整游标 1 重新订阅。一条提问只提交一次，重开后的 HTML 与终态一致，两名临时账号均已停用。按用户决定保持共享 Worker 运行。目标上的同一 Job 在快照后进入新 attempt 并发出 reset 仍待验收（4.4）。

补验目标 HTTP 的退出与并发续期。独立 Chrome 中三个并发的应用列表请求均遇到凭据过期，插件合并为一次静默兑换，三个请求随后均返回 200。测试用户通过平台的本人会话接口结束自己的插件授权父会话。重新打开插件提示登录，应用列表为空。用原账号在平台页面重新登录并同意后，再次看到已授权应用。本次提交 Job 数为 0，临时账号已停用。
